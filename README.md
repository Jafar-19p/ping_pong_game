# Classic Ping Pong Game

A clean, object-oriented implementation of the classic ping pong game built in Python using the **turtle** graphics library. This project illustrates core OOP principles, clean file organization, inheritance, and robust game logic handling.

## Features

- **Two-Player Controls:** Smooth, responsive paddle movement for local dual-player gameplay.
- **Dynamic Scoreboard:** Automated score tracking and real-time screen updates upon goal scoring.
- **Progressive Ball Acceleration:** Speed dynamically scales with every successful paddle collision to increase difficulty.
- **Modular OOP Architecture:** Clean, well-structured codebase divided into separate classes (`Paddle`, `Ball`, `Score`) for enhanced maintainability.

## Built With

- **Python:** Version 3.14.7
- **Turtle Graphics:** Built-in standard library for UI rendering and game animation
- **PyInstaller:** Packaging tool used to compile the application into a standalone executable (.exe)
